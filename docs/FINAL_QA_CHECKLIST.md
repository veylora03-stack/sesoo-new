# چک‌لیست تست نهایی (QA)

- [ ] صفحه اصلی به درستی لود می‌شود و المان‌های اصلی نمایش داده می‌شوند.
- [ ] صفحه درباره ما و محتوای آن صحیح است.
- [ ] لیست خدمات و صفحات جزئیات خدمات (طراحی سایت، سئو) کار می‌کنند.
- [ ] لیست نمونه‌کارها و صفحه جزئیات نمونه‌کار بدون خطا نمایش داده می‌شود.
- [ ] لیست مقالات وبلاگ و صفحه جزئیات مقاله به درستی کار می‌کنند.
- [ ] فرم تماس (لید) به درستی نمایش داده شده و ارسال می‌شود.
- [ ] لید ثبت شده در پنل ادمین قابل مشاهده و مدیریت است.
- [ ] نقش‌ها و دسترسی‌های ادمین به درستی محدود شده‌اند.
- [ ] فایل robots.txt در دسترس است و مسیرهای صحیح را مسدود کرده است.
- [ ] فایل sitemap.xml تولید شده و شامل URLهای صحیح است.
- [ ] Schema Markup در صفحات خدمات، مقالات و نمونه‌کارها معتبر است.
- [ ] هدرهای امنیتی (Security Headers) در پاسخ‌ها وجود دارند.
- [ ] صفحه خطای 404 برای آدرس‌های نامعتبر نمایش داده می‌شود.
- [ ] صفحه خطای 500 به درستی طراحی شده است.
- [ ] سایت در موبایل و تبلت به درستی ریسپانسیو است.
- [ ] سرعت لود صفحات اصلی قابل قبول است.
- [ ] سیستم بکاپ‌گیری دیتابیس و فایل‌ها تست شده است.
- [ ] فرآیند استقرار (Deployment) روی سرور تست موفقیت‌آمیز بوده است.
