# چک‌لیست نهایی قبل از لانچ (Go Live)

- [ ] دامنه (Domain) ثبت و DNSها به سرور پروداکشن ست شده‌اند.
- [ ] گواهی SSL (HTTPS) فعال و به درستی تنظیم شده است.
- [ ] متغیر `DEBUG=False` در محیط production تنظیم شده است.
- [ ] یک `SECRET_KEY` قوی، تصادفی و محرمانه تولید و ست شده است.
- [ ] `ALLOWED_HOSTS` فقط شامل دامنه‌های اصلی و معتبر است.
- [ ] دیتابیس PostgreSQL پیکربندی، migrate و تست شده است.
- [ ] سرویس Redis برای کش در صورت نیاز فعال و در دسترس است.
- [ ] دستور `collectstatic` اجرا شده و فایل‌های استاتیک توسط Nginx/WhiteNoise سرو می‌شوند.
- [ ] مسیر `media` روی سرور پیکربندی شده و دسترسی نوشتن دارد.
- [ ] سیستم بکاپ‌گیری خودکار برای دیتابیس و media فعال است.
- [ ] فرم تماس (Lead) تست شده و لیدها به درستی در ادمین ثبت می‌شوند.
- [ ] سیستم اطلاع‌رسانی ایمیلی (در صورت فعال بودن) تست شده است.
- [ ] کد Google Search Console ست شده و سایت وریفای شده است.
- [ ] کد Google Analytics یا ابزار مانیتورینگ مشابه در `base.html` قرار داده شده است.
- [ ] لاگ‌های Gunicorn و Nginx به درستی به فایل یا stdout هدایت می‌شوند.
- [ ] امنیت پنل ادمین بررسی شده است (استفاده از Axes و رمزهای قوی).
- [ ] سرعت سایت با ابزارهایی مثل PageSpeed Insights بررسی شده است.
- [ ] سایت در دستگاه‌های موبایل به درستی تست شده است.
- [ ] فایل‌های `robots.txt` و `sitemap.xml` در دامنه اصلی چک شده‌اند.
- [ ] صفحات خطای 404 و 500 با وارد کردن آدرس اشتباه تست شده‌اند.
