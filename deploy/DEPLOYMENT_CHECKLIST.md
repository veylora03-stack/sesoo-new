# چک‌لیست استقرار پروداکشن

- [ ] دامنه (Domain) ثبت و ست شده است.
- [ ] رکوردهای DNS به سرور اشاره می‌کنند.
- [ ] گواهی SSL تهیه و فعال شده است.
- [ ] `SECRET_KEY` به یک مقدار تصادفی و قوی تغییر یافته است.
- [ ] `ALLOWED_HOSTS` فقط شامل دامنه‌های معتبر است.
- [ ] `DEBUG` روی `False` تنظیم شده است.
- [ ] دیتابیس PostgreSQL پیکربندی و در دسترس است.
- [ ] سرویس Redis برای کش در دسترس است.
- [ ] فایل‌های استاتیک (`staticfiles`) به درستی collect شده‌اند.
- [ ] مسیر `media` برای آپلود فایل‌ها پیکربندی شده است.
- [ ] سیستم بکاپ‌گیری خودکار برای دیتابیس و media فعال است.
- [ ] مانیتورینگ سرور و آپتایم سایت تنظیم شده است.
- [ ] لاگ‌های Gunicorn و Caddy به درستی ذخیره و بررسی می‌شوند.
- [ ] Rate limit برای فرم‌های حساس (مثل لاگین ادمین) فعال است.
- [ ] کد تایید Google Search Console در تنظیمات سایت وارد شده است.
- [ ] فایل `robots.txt` و `sitemap.xml` در دسترس و صحیح هستند.
